# 📁 File Organizer

Script em Shell que organiza automaticamente arquivos de uma pasta por tipo (imagens, vídeos, documentos, etc).

## 🚀 Como usar

```bash
# Organizar a pasta atual
./file_organizer.sh

# Organizar uma pasta específica
./file_organizer.sh /caminho/da/pasta
```

## 📂 Categorias

| Pasta | Extensões |
|-------|-----------|
| images | jpg, jpeg, png, gif, svg, webp |
| videos | mp4, avi, mkv, mov |
| audio | mp3, wav, ogg, flac |
| documents | pdf, doc, docx, txt |
| archives | zip, tar, gz, rar |
| code | sh, py, js, html, css |
| others | todo o resto |

## 🛠 Tecnologias
- Bash / Shell Script
- Comandos: `for`, `case`, `mv`, `mkdir`
